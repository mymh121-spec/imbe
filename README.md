# 맨손 추적 기반 3차원 가상 지휘 인터페이스 및 실시간 오디오 믹싱 시스템

노트북 카메라로 맨손의 21개 관절을 추적하고, 상대적인 위치와 방향을 Three.js 지휘봉과 Web Audio API 믹서에 전달하는 로컬 웹앱입니다. 영상과 오디오는 브라우저 안에서만 처리하며 서버로 전송하지 않습니다.

## 실행

요구 사항은 Node.js 22.13 이상과 카메라가 연결된 최신 Chrome 또는 Edge입니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 `http://localhost:3000`을 여세요. 카메라 API는 보안 컨텍스트가 필요하므로 파일을 직접 열지 말고 반드시 `localhost` 개발 서버에서 실행합니다.

검증 명령:

```bash
npm run typecheck
npm test
npm run build
```

## 빠른 사용 순서

1. 처음에는 `SIM` 모드입니다. 3D 무대를 클릭한 뒤 마우스를 드래그하면 X/Y, 휠을 돌리면 Z 깊이가 변합니다.
2. `재생` 버튼을 누르면 세 개의 내장 합성음이 시작됩니다. 브라우저 자동 재생 정책 때문에 첫 재생은 사용자 클릭이 필요합니다.
3. 카메라 입력 탭에서 `카메라 켜기`를 누르고 권한을 허용합니다.
4. 손바닥 전체를 카메라에 보입니다. 처음 한 번은 로컬 손 모델 준비에 몇 초가 걸릴 수 있습니다.
5. 손바닥 중심을 움직이면 검선과 3D 지휘봉이 함께 움직입니다. 카메라에 보이는 손 크기가 Z 깊이와 전체 음량에 반영됩니다.
6. `손 명령`을 켜면 주먹·손바닥·엄지·핀치 동작이 오디오 명령으로 실행됩니다. 안전을 위해 기본값은 OFF입니다.
7. `박자 동기화`를 켜면 하강 후 반전되는 지휘 궤적의 BPM이 오디오 템포에 반영됩니다.
8. 개인화된 명령 분류가 필요하면 `학습` 탭에서 샘플을 모아 로컬 TCN 모델을 학습합니다.

손이 검출되면 카메라 미리보기에 손 골격, 발광 검선과 검 끝의 짧은 이동 잔상이 표시됩니다.

카메라 권한을 거부한 경우 주소 표시줄의 사이트 권한에서 카메라를 허용한 뒤 새로고침하세요. 카메라 없음, 권한 거부, 연결 오류, 손 모델 준비와 손 미검출 상태는 입력 패널과 상단 상태 표시줄에 구분되어 표시됩니다.

## 맨손 추적과 상대 깊이

공식 MediaPipe Hand Landmarker로 손의 21개 관절을 검출합니다. 손바닥 중심을 X/Y, 검지와 새끼손가락 밑 관절 사이 폭을 상대 Z 깊이, 손목에서 중지 밑 관절로 향하는 벡터를 검선 방향으로 사용합니다.

Z는 카메라와 손 사이의 cm 값을 재는 기능이 아닙니다. 화면에서 손바닥 폭이 약 7%일 때 0, 약 29%일 때 1이 되도록 제한한 상대값이며, 손을 가까이 가져오면 커지는 정도만 안정적으로 사용합니다. 이 값은 `BatonController`의 저역통과 평활화를 거친 후 음량에 전달되므로 정밀 캘리브레이션 없이 지휘 강약을 조절할 수 있습니다.

손 명령은 한 프레임만으로 실행하지 않습니다. 주먹은 음소거, 펼친 손바닥은 음소거 해제, 엄지 위·아래는 템포 ±10, 핀치를 유지한 상하 이동은 크레센도·디크레센도, 핀치 좌우 이동은 밸런스로 매핑됩니다. 정적 명령은 약 420ms 유지해야 하며 실행 후 쿨다운과 손 모양 해제를 거쳐야 다시 실행됩니다.

박자 추적기는 손이나 시뮬레이션 지휘봉이 아래로 이동한 뒤 방향을 바꾸는 지점을 박자로 계산합니다. 최근 박자 간격의 중앙값으로 BPM을 산출하며 2박·3박·4박 패턴을 선택할 수 있습니다. 작은 흔들림, 250ms보다 짧은 중복 입력과 1.5초보다 긴 간격은 안정성을 위해 제외합니다.

WASM과 `hand_landmarker.task` 모델은 `public/mediapipe`에 포함되어 있어 실행 중 CDN을 사용하지 않습니다. 모델은 [Google MediaPipe 공식 Hand Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker/web_js)에서 제공하는 파일이며, 카메라 프레임은 외부로 업로드되지 않습니다. 손 전체가 화면에 들어오고 손바닥 윤곽이 배경과 구분되는 밝기에서 가장 안정적으로 동작합니다. ArUco·AprilTag·OpenCV는 사용하지 않습니다.

## 개인 제스처 모델 학습

`학습` 탭은 TensorFlow.js 경량 TCN을 브라우저에서 직접 학습합니다. 원본 영상은 저장하지 않고, 손목 기준으로 정규화한 21개 관절과 손 중심·상대 크기 특징만 24프레임 단위로 IndexedDB에 저장합니다.

1. 카메라를 켜고 손이 인식된 상태에서 `학습` 탭을 엽니다.
2. 수집할 명령 버튼을 누르고 2초 카운트다운 뒤 약 1.3초 동안 해당 동작을 수행합니다.
3. `기타 / 대기`를 포함한 9개 명령을 각각 최소 5회 수집합니다.
4. `모델 학습`을 누르면 35 epoch 학습 후 모델이 IndexedDB에 저장됩니다.
5. 검증 정확도를 확인한 다음 `학습 모델` 스위치를 켭니다. `손 명령` 안전 스위치도 켜야 실제 오디오 명령이 실행됩니다.

5개/명령은 학습 기능을 확인하기 위한 최소값입니다. 실제 사용에는 조명·위치·속도를 바꿔 명령별 50~100개 이상을 수집하고 별도 세션에서 오작동을 확인하는 것이 좋습니다. 모델 예측은 신뢰도 90%, 220ms 유지와 850ms 쿨다운을 통과해야 실행됩니다. 학습 모델을 끄거나 모델이 없으면 기존 규칙 기반 판정으로 자동 폴백합니다.

## 오디오

`오디오 불러오기`에서 최대 3개의 로컬 오디오 파일을 고를 수 있습니다. 선택 순서대로 트랙 1~3에 배치되고, 파일을 선택하지 않은 트랙은 테스트 합성음을 사용합니다. 각 트랙에는 개별 GainNode, 저음/중음/고음 BiquadFilterNode 체인, StereoPannerNode가 있습니다.

기본 테스트 합성음은 A4 440 Hz와 2·3차 배음인 880 Hz, 1320 Hz로 구성됩니다. `사인파`, `삼각파`, `사각파` 버튼을 누르면 카메라 없이 해당 파형의 테스트톤이 즉시 재생됩니다. 옆의 수동 동작 패널에서 `<` 디크레센도, `>` 크레센도, 음소거, 60~180 BPM 템포, 좌우 소리 가중치를 조절할 수 있습니다. 강약은 10% 단위로 바뀌며 약 0.8초 동안 부드럽게 적용됩니다.

- X 위치: 스테레오 패닝
- Y 위치: 저음/고음 EQ 균형
- Z 깊이: 마스터 음량
- 지휘봉 기울기: EQ 변화량
- 이동 속도: EQ 반응 강도
- 급정지: 기본값은 짧은 감쇠, 설정에서 일시정지 또는 끄기 선택 가능

모든 AudioParam 변화에는 짧은 `setTargetAtTime` 램프가 적용됩니다. 손이 사라지면 450ms 동안 마지막 자세를 유지한 뒤 안전 음량으로 감쇠합니다.

## 시뮬레이션 조작

3D 무대를 클릭해 포커스를 둔 뒤 사용합니다.

| 입력 | 동작 |
| --- | --- |
| 마우스 드래그 | X/Y 이동 |
| 마우스 휠 | Z 깊이 |
| W/A/S/D | 상/좌/하/우 이동 |
| R/F | 가까이/멀리 |
| 방향키 | Pitch/Yaw |
| Q/E | Roll |
| Space | 기준 자세로 초기화 |
| Shift + 키 | 큰 이동 단위 |

카메라와 시뮬레이션은 `BatonController`의 평활화와 `gestureMapping`을 똑같이 통과하므로 화면과 오디오 반응을 카메라 없이 점검할 수 있습니다.

## 코드 구조

- `modules/cameraInput.ts`: 카메라 권한, 스트림 시작/정지, 오류 분류
- `modules/handDetection.ts`: MediaPipe 손 관절 검출, 상대 X/Y/Z와 방향 계산, 손 골격 오버레이
- `modules/cameraBatonOverlay.ts`: 카메라 위 발광 검선과 이동 잔상 렌더러
- `modules/batonController.ts`: 저역통과 평활화, 속도/급정지, 손 유실 hold/idle 상태
- `modules/gestureMapping.ts`: 공통 포즈에서 오디오 파라미터로의 매핑
- `modules/gestureFeatures.ts`: 손가락 비율 기반 주먹·손바닥·엄지·핀치 특징
- `modules/gestureCommands.ts`: 명령 유지 시간, 핀치 방향, 쿨다운과 안전 실행
- `modules/gestureModelFeatures.ts`: 손 랜드마크 정규화, 24프레임 버퍼와 학습 명령 안전 게이트
- `modules/gestureModel.ts`: TensorFlow.js TCN, IndexedDB 데이터·모델 저장, 학습과 추론
- `modules/beatTracker.ts`: 지휘 궤적의 박자 카운트, 박자 패턴과 BPM 계산
- `modules/audioEngine.ts`: 3트랙 Web Audio 그래프, 파일/합성음, 재생 상태
- `modules/visualizer.ts`: Three.js 지휘봉, 위치/회전, 이동 잔상
- `modules/simulationMode.ts`: 마우스·키보드 포즈 입력

## 브라우저 확인 체크리스트

- 카메라 ON 시 권한 요청과 상태 문구 확인
- 손 추적에서 손 골격·검선과 X/Y/상대 Z 반응 확인
- 손 명령 ON에서 주먹·손바닥·엄지·핀치 명령과 쿨다운 확인
- 학습 탭에서 9개 명령의 샘플 수집 상태와 TensorFlow.js 모델 상태 확인
- 시뮬레이션 또는 손 추적에서 박자 카운트와 BPM, 2·3·4박 전환 확인
- 손을 좌우/상하/앞뒤로 움직여 X/Y/Z와 지휘봉 반응 확인
- 재생 중 X→패닝, Y→EQ, Z→마스터 음량 확인
- 손을 화면에서 치워 hold 이후 음량이 감쇠되는지 확인
- SIM 모드에서 마우스, 휠, 키보드와 3개 트랙 믹서 확인
- 새로고침 후 기본 화면이 오류 없이 복원되는지 확인

실제 카메라 검증 및 고도화 항목은 [`FUTURE.md`](./FUTURE.md)에 별도로 관리합니다.

규칙 기반 박자 인식과 개인화 TCN 명령 모델의 구조·안전 기준은 [`chuhu.md`](./chuhu.md)에 정리했습니다.

# 손등 부착형 다중 마커를 이용한 3차원 가상 지휘 인터페이스 및 실시간 오디오 믹싱 시스템

노트북 카메라로 손등의 ArUco 마커 2~3개를 하나의 평면 보드로 추적하고, 그 자세를 Three.js 지휘봉과 Web Audio API 믹서에 전달하는 로컬 웹앱입니다. 영상과 오디오는 브라우저 안에서만 처리하며 서버로 전송하지 않습니다.

## 실행

요구 사항은 Node.js 22.13 이상과 카메라가 연결된 최신 Chrome 또는 Edge입니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 `http://localhost:3000`을 여세요. 카메라 API는 보안 컨텍스트가 필요하므로 파일을 직접 열지 말고 반드시 `localhost` 개발 서버에서 실행합니다.

검증 명령:

```bash
npm run typecheck
npm test
npm run build
```

## 빠른 사용 순서

1. 처음에는 `SIM` 모드입니다. 3D 무대를 클릭한 뒤 마우스를 드래그하면 X/Y, 휠을 돌리면 Z 깊이가 변합니다.
2. `재생` 버튼을 누르면 세 개의 내장 합성음이 시작됩니다. 브라우저 자동 재생 정책 때문에 첫 재생은 사용자 클릭이 필요합니다.
3. 카메라 입력 탭에서 `카메라 켜기`를 누르고 권한을 허용합니다.
4. 출력한 ID 0, 1, 2 마커를 카메라에 보여 준 뒤 `CAM` 모드를 사용합니다.
5. 손을 기준 위치에 고정하고 보정 탭의 `영점 보정`을 누릅니다.

카메라 권한을 거부한 경우 주소 표시줄의 사이트 권한에서 카메라를 허용한 뒤 새로고침하세요. 카메라 없음, 권한 거부, 연결 오류, 마커 미검출 상태는 입력 패널과 상단 상태 표시줄에 구분되어 표시됩니다.

## 마커 출력과 부착

보정 탭의 `마커 출력`은 현재 설정된 ID로 A4 인쇄 페이지를 엽니다. 인쇄 배율은 100%로 설정하고, 검은 정사각형 외곽의 실제 크기가 `마커 크기` 값과 같은지 자로 확인하세요.

기본 보드는 다음 중심 좌표를 사용합니다. 좌표 원점은 세 마커 사이의 보드 중심이고, 모든 마커는 같은 평면에 같은 방향으로 부착합니다.

| ID | X (mm) | Y (mm) |
| --- | ---: | ---: |
| 0 | -34 | -18 |
| 1 | 34 | -18 |
| 2 | 0 | 26 |

실제 부착 위치가 다르면 보정 탭의 ID/X/Y 값을 실측값으로 바꾸세요. 3개 중 1개가 가려져도 남은 마커 모서리로 보드 포즈를 다시 계산합니다. 한 개만 보이는 경우도 동작하지만 회전과 깊이 안정성은 낮아질 수 있습니다.

현재 구현은 `js-aruco`의 고전 5x5 ArUco 사전(ID 0~1023)을 사용합니다. OpenCV.js 공식 기본 배포본에서는 ArUco/Board 바인딩 제공 여부가 버전과 빌드 옵션에 따라 일관되지 않아, CDN이나 사용자 정의 OpenCV WASM 빌드 없이 로컬 실행이 확실한 순수 JavaScript 검출기를 선택했습니다. 다중 마커 포즈는 검출된 모든 모서리와 실제 보드 좌표를 사용하는 평면 호모그래피 분해로 별도 구현했습니다.

## 카메라와 거리 보정

보정 탭에서 다음 순서로 설정합니다.

1. 인쇄된 검은 외곽 사각형 한 변의 길이를 `마커 크기`에 입력합니다.
2. 노트북 카메라 사양의 수평 화각을 알면 `수평 화각`에 입력합니다. 모르면 기본 60도로 시작합니다.
3. 마커 중심 사이 거리를 재서 각 마커의 X/Y 좌표를 입력합니다.
4. 손을 화면 중앙, 평상시 지휘 거리(권장 35~45cm)에 두고 마커가 2개 이상 검출된 상태에서 `영점 보정`을 누릅니다.
5. 움직임이 너무 크거나 작으면 X 이동 범위와 깊이 범위를 조정합니다.

일반 노트북 카메라의 렌즈 왜곡 계수까지 구하는 체커보드 캘리브레이션은 포함하지 않습니다. 이 앱은 절대 거리 측정보다 기준 자세 대비 상대 X/Y/Z의 안정성을 우선합니다. 정확한 mm 단위가 필요하면 카메라의 실제 내부 파라미터와 왜곡 보정이 추가로 필요합니다.

## 오디오

`오디오 불러오기`에서 최대 3개의 로컬 오디오 파일을 고를 수 있습니다. 선택 순서대로 트랙 1~3에 배치되고, 파일을 선택하지 않은 트랙은 테스트 합성음을 사용합니다. 각 트랙에는 개별 GainNode, 저음/중음/고음 BiquadFilterNode 체인, StereoPannerNode가 있습니다.

- X 위치: 스테레오 패닝
- Y 위치: 저음/고음 EQ 균형
- Z 깊이: 마스터 음량
- 지휘봉 기울기: EQ 변화량
- 이동 속도: EQ 반응 강도
- 급정지: 기본값은 짧은 감쇠, 설정에서 일시정지 또는 끄기 선택 가능

모든 AudioParam 변화에는 짧은 `setTargetAtTime` 램프가 적용됩니다. 마커가 사라지면 450ms 동안 마지막 자세를 유지한 뒤 안전 음량으로 감쇠합니다.

## 시뮬레이션 조작

3D 무대를 클릭해 포커스를 둔 뒤 사용합니다.

| 입력 | 동작 |
| --- | --- |
| 마우스 드래그 | X/Y 이동 |
| 마우스 휠 | Z 깊이 |
| W/A/S/D | 상/좌/하/우 이동 |
| R/F | 가까이/멀리 |
| 방향키 | Pitch/Yaw |
| Q/E | Roll |
| Space | 기준 자세로 초기화 |
| Shift + 키 | 큰 이동 단위 |

카메라와 시뮬레이션은 `BatonController`의 평활화와 `gestureMapping`을 똑같이 통과하므로 화면과 오디오 반응을 카메라 없이 점검할 수 있습니다.

## 코드 구조

- `modules/cameraInput.ts`: 카메라 권한, 스트림 시작/정지, 오류 분류
- `modules/markerDetection.ts`: ArUco ID/네 모서리 검출과 미리보기 오버레이
- `modules/poseEstimation.ts`: 다중 마커 보드 호모그래피 및 3D 자세 추정
- `modules/batonController.ts`: 저역통과 평활화, 속도/급정지, 마커 유실 hold/idle 상태
- `modules/gestureMapping.ts`: 공통 포즈에서 오디오 파라미터로의 매핑
- `modules/audioEngine.ts`: 3트랙 Web Audio 그래프, 파일/합성음, 재생 상태
- `modules/visualizer.ts`: Three.js 지휘봉, 위치/회전, 이동 잔상
- `modules/calibration.ts`: 보드/카메라 설정, 영점, 마커 SVG 출력, 로컬 저장
- `modules/simulationMode.ts`: 마우스·키보드 포즈 입력

## 브라우저 확인 체크리스트

- 카메라 ON 시 권한 요청과 상태 문구 확인
- ID 0/1/2의 윤곽선과 ID 오버레이 확인
- 보드를 좌우/상하/앞뒤로 움직여 X/Y/Z와 지휘봉 반응 확인
- 재생 중 X→패닝, Y→EQ, Z→마스터 음량 확인
- 마커를 가려 hold 이후 음량이 감쇠되는지 확인
- SIM 모드에서 마우스, 휠, 키보드와 3개 트랙 믹서 확인
- 새로고침 후 기본 화면과 저장된 보정값이 오류 없이 복원되는지 확인
